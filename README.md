# Dmais Comunicação Visual

Site institucional da Dmais Comunicação Visual, desenvolvido para apresentar a empresa, seus serviços, projetos realizados e canais de contato.

## Tecnologias utilizadas

- React
- TypeScript
- TanStack Start
- TanStack Router
- Vite
- Tailwind CSS
- Supabase
- Drizzle ORM

## Requisitos

- Node.js
- Bun

## Instalação

Clone o repositório e acesse a pasta do projeto.

Instale as dependências:

`bun install`

## Configuração

Configure as variáveis de ambiente necessárias no arquivo `.env`, incluindo as credenciais do Supabase.

Nunca compartilhe chaves privadas ou credenciais.

## Executar localmente

`bun run dev`

## Build de produção

`bun run build`

## Testes

`bun run test`
